# 🕹️ Tic Tac Toe (Python Console Game)

This is a simple Python-based **Tic Tac Toe** game that runs in the console.  
Players take turns entering positions (0–8), and the game detects wins, draws, and allows replay.

---

## 📌 Features
- Two-player console gameplay (X vs O)
- Valid move checks (no overwriting)
- Win detection for all 8 possible patterns
- Draw detection
- Option to replay after game ends
- Clear and easy-to-read board display
